# WAY — Men's Wear

A complete Vite + React + TypeScript + Tailwind menswear storefront inspired by the supplied cinematic GSAP footer prompt.

## Run
1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Build
`npm run build`

## Included
- Responsive WAY men's fashion storefront
- Dark navy / icy-blue visual system
- Animated GSAP hero and cinematic footer
- Product filtering
- Wishlist interactions
- Shopping bag drawer
- Search UI
- Responsive mobile navigation
- Tailwind CSS + TypeScript
- shadcn-style `/src/components/ui` structure
- Lucide icons

Product/editorial images currently use remote Unsplash URLs and can be replaced with the shop's own photography later.
